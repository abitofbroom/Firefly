## 位运算

按位左移 `<<`：全部向左移位，高位舍去，末尾补零

```c
0011 1100 << 1 -> 0111 1000
```

按位右移 `>>`：全部向右移位，高位补零，低位舍去

```c
0011 1100 >> 2 -> 0000 1111
```

按位与 `&` —— 有 0 则 0

```c
1100 0101 & 0011 1100 —> 0000 0100
```

按位或 `|` —— 有 1 则 1

```c
0001 1000 | 0010 1010 -> 0011 1010
```

按位异或 `^` —— 同 0 异 1

```c
0001 1000 ^ 0010 1010 -> 0011 0010
```

按位取反 `~`

```c
~0001 1000 -> 1110 0111
```
