## 为什么需要 RTC

单片机一断电就丢时间。DS1302 自带 32.768 kHz 晶振和备用电池，主电断了继续走时，再用 3 根线把时间交给单片机。

这篇是 `10-1 DS1302时钟` 工程的小结：DS1302 + LCD1602，第一行显示年月日，第二行显示时分秒。编译结果 `data=45.0 xdata=0 code=1362`。

## 引脚（8 脚）

| 脚 | 名称 | 作用 |
| --- | --- | --- |
| 1 | VCC2 | 主电源（5V / 3.3V） |
| 2、3 | X1、X2 | 32.768 kHz 晶振两端（各配 6pF 左右负载电容） |
| 4 | GND | 地 |
| 5 | CE（旧称 RST） | 片选，**高电平有效**：拉高开始一次通信，拉低结束 |
| 6 | I/O | 双向数据线（半双工，读写共用） |
| 7 | SCLK | 串行时钟，由单片机给出，空闲为低 |
| 8 | VCC1 | 备用电源（纽扣电池 / 超级电容） |

VCC1 / VCC2 自动切换：芯片用电压高的那一路，所以主电掉电后靠 VCC1 继续走时，主电恢复后再切回来。

## 命令字节：所有通信的起点

每次读写先发 1 个命令字节：

| 位 | 含义 |
| --- | --- |
| bit7 | 固定为 1 |
| bit6 | 0 = 时钟寄存器，1 = RAM |
| bit5~bit1 | 寄存器地址 |
| bit0 | 1 = 读，0 = 写 |

口诀：**读写只差最低位**。工程里头文件只定义写地址，读函数内部 `Command |= 0x01` 自动转成读地址。

## 寄存器地图

| 寄存器 | 写地址 | 位域（bit7…bit0） |
| --- | --- | --- |
| 秒 SECOND | 0x80 | **CH** · 10SEC(6-4) · SEC(3-0) |
| 分 MINUTE | 0x82 | 0 · 10MIN(6-4) · MIN(3-0) |
| 时 HOUR | 0x84 | **12/24** · AP(12h 时) · 10HR(5-4) · HR(3-0) |
| 日 DATE | 0x86 | 0 · 0 · 10DATE(5-4) · DATE(3-0) |
| 月 MONTH | 0x88 | 0 · 0 · 0 · 10M(4) · MONTH(3-0) |
| 星期 DAY | 0x8A | … · DAY(2-0)，1~7 由自己定义 |
| 年 YEAR | 0x8C | 10YR(7-4) · YR(3-0)，00~99 |
| 写保护 WP | 0x8E | **WP**(7)：1 = 保护，0 = 可写 |
| 涓流充电 | 0x90 | TCS(7-4) · DS(3-2) · RS(1-0) |
| 时钟突发 | 0xBE / 0xBF | 一次连续读写上面 8 个寄存器 |
| RAM | 0xC0~0xFC / 0xC1~0xFD | 31 字节通用 RAM |

两个关键位：

- **CH**（秒寄存器 bit7）= Clock Halt，1 表示振荡器停。上电默认常常是 1，不清 0 就不走时。
- **WP**（0x8E 的 bit7）= 1 时只读，写之前要解锁。

## BCD 编码

DS1302 里的时间是 **BCD 码**：用 4 位二进制数表示 1 位十进制数，所以高 4 位是十位、低 4 位是个位。23 点存 `0x23`，59 秒存 `0x59`。

2 位 BCD 的换算（工程里就是这么写的）：

```c
// BCD -> 十进制：DEC = BCD / 16 * 10 + BCD % 16
unsigned char BCD2DEC(unsigned char b) { return b / 16 * 10 + b % 16; }

// 十进制 -> BCD：BCD = DEC / 10 * 16 + DEC % 10
unsigned char DEC2BCD(unsigned char d) { return d / 10 * 16 + d % 10; }
```

## 读写时序

- 拉高 CE 开始一次通信，拉低 CE 结束（I/O 变高阻）
- 每个字节**低位先发**
- **写**：数据在 SCLK **上升沿**被芯片采走 → 先摆好数据再给上升沿
- **读**：芯片在 SCLK **下降沿**后把数据放到 I/O → 拉低 SCLK 后再采样

```c
// 写一个字节
void DS1302_WriteByte(unsigned char Command, unsigned char Data)
{
    unsigned char i;
    DS1302_CE = 1;
    for(i = 0; i < 8; i++) { DS1302_IO = Command & (0x01 << i); DS1302_SCLK = 1; DS1302_SCLK = 0; }
    for(i = 0; i < 8; i++) { DS1302_IO = Data    & (0x01 << i); DS1302_SCLK = 1; DS1302_SCLK = 0; }
    DS1302_CE = 0;
}

// 读一个字节
unsigned char DS1302_ReadByte(unsigned char Command)
{
    unsigned char i, Data = 0x00;
    Command |= 0x01;                    // 写地址 -> 读地址
    DS1302_CE = 1;
    for(i = 0; i < 8; i++) { DS1302_IO = Command & (0x01 << i); DS1302_SCLK = 0; DS1302_SCLK = 1; }
    for(i = 0; i < 8; i++) { DS1302_SCLK = 1; DS1302_SCLK = 0; if(DS1302_IO) Data |= (0x01 << i); }
    DS1302_CE = 0;
    return Data;
}
```

注意读和写的边沿顺序是**相反**的：读命令用「先低后高」，读数据用「先高后低」，然后才采样——对应芯片"下降沿输出"。

### 关于 SCLK 之间的延时

DS1302 是靠 SCLK 的边沿采样的，所以**两次电平变化之间要留一点时间**，比如 `DS1302_SCLK = 0` 变成 `1` 之后、再变回 `0` 之前。

51 的 GPIO 翻转本身比较慢（12MHz 下一条指令约 1µs），一般不加显式延时也能稳定通信；但如果换成更快的单片机，或者编译器把相邻的赋值优化得很紧，就要在两次 SCLK 变化之间插 `_nop_()` 之类的短延时，否则数据会错位。

## 设置与读取时间

```c
sbit DS1302_SCLK = P3^6;
sbit DS1302_IO   = P3^4;
sbit DS1302_CE   = P3^5;

unsigned char DS1302_Time[7] = {25, 1, 1, 0, 0, 0, 1};   // 年 月 日 时 分 秒 星期

void DS1302_SetTime(void)
{
    DS1302_WriteByte(0x8E, 0x00);                       // 关写保护
    DS1302_WriteByte(0x8C, DEC2BCD(DS1302_Time[0]));    // 年
    DS1302_WriteByte(0x88, DEC2BCD(DS1302_Time[1]));    // 月
    DS1302_WriteByte(0x86, DEC2BCD(DS1302_Time[2]));    // 日
    DS1302_WriteByte(0x84, DEC2BCD(DS1302_Time[3]));    // 时
    DS1302_WriteByte(0x82, DEC2BCD(DS1302_Time[4]));    // 分
    DS1302_WriteByte(0x80, DEC2BCD(DS1302_Time[5]));    // 秒（bit7=0 顺带清 CH，振荡器起振）
    DS1302_WriteByte(0x8A, DEC2BCD(DS1302_Time[6]));    // 星期
    DS1302_WriteByte(0x8E, 0x80);                       // 开写保护
}
```

读时间就是反过来：逐寄存器读出 → `BCD2DEC` → 存回数组，顺序固定「年 月 日 时 分 秒 星期」。

主程序骨架：

```c
LCD_Init();
DS1302_Init();
DS1302_SetTime();
while(1)
{
    DS1302_ReadTime();
    LCD_ShowNum(1, 1, DS1302_Time[0], 2);   // 年
    LCD_ShowNum(1, 4, DS1302_Time[1], 2);   // 月
    LCD_ShowNum(1, 7, DS1302_Time[2], 2);   // 日
    LCD_ShowNum(2, 1, DS1302_Time[3], 2);   // 时
    LCD_ShowNum(2, 4, DS1302_Time[4], 2);   // 分
    LCD_ShowNum(2, 7, DS1302_Time[5], 2);   // 秒
}
```

## 常见坑

1. **每次复位都把时间改回初始值**。`main` 里无条件调 `DS1302_SetTime()`，一按复位就重写时间，电池备份等于白搭。正确做法：只在「按键设置时间」时调用，或先读 CH 位判断是否停振再决定要不要设。
2. **CH 位没清**：只读不写、发现不走时，先看秒寄存器 bit7 是不是 1。
3. **WP 没解锁**：写不进去。`0x8E ← 0x00` 解锁、`0x8E ← 0x80` 上锁。
4. **读写地址差 1**：`0x80` 写、`0x81` 读。
5. **BCD 当十进制**：`0x59` 直接当 59 显示是错的（会显示 89）。
6. **12/24 小时模式**：时寄存器 bit7。用 24 小时模式最省事，读回来 bit7 应为 0。
7. **星期是自己填的 1~7**：芯片不会算星期几。
8. **编译时的 L16 警告**：`LCD_ShowString`、`LCD_ShowHexNum` 等函数没被调用，链接器提示"未调用的段"，不是错误。

## 精度与选型

DS1302 没有温度补偿，日误差可能到秒级，学习够用。实际产品一般用 DS3231（I²C 接口、内置 TCXO、±2ppm）。

## 一句话记住

**三根线、先命令后数据、低位先出、写升读降、BCD 存储、CH 启动、WP 解锁、0x80 写 / 0x81 读。**
