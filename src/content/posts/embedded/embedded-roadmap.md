## 这篇是干什么的

我的嵌入式是从 **51 单片机（STC89C52）** 入门的。这篇把路线整理成清单，按顺序推进，学完一项打一个勾，学过的内容在下面的「笔记索引」里能找到对应笔记。

> [!TIP]
> 51 是打基础用的：重点不是背下 STC89C52 的每个寄存器，而是搞懂「配置寄存器 → 控制硬件」这套思路。把这套思路吃透，之后转到 STM32 会快很多。

## 阶段一：开发环境与 C51 基础

- [x] 开发板与芯片认识：STC89C52、最小系统、晶振（11.0592 MHz / 12 MHz）
- [x] Keil 建工程、编译、用 STC-ISP 下载程序
- [x] C51 基本语法：数据类型、判断与循环
- [x] 位运算：按位与/或/异或/取反、左移与右移
- [x] 寄存器位操作与位定义（`sbit`）
- [x] 点亮 LED 与延时函数 Delay
- [ ] 看懂原理图与数据手册：引脚定义、时序图

## 阶段二：基础外设

- [x] 独立按键与按键消抖
- [x] 数码管：静态显示、动态扫描（输出扫描）
- [x] 数码管消影：数据传输延迟导致的串位与重影问题
- [x] LCD1602 液晶显示（含接线与调试踩坑）
- [ ] 蜂鸣器与继电器

## 阶段三：中断与定时器

- [x] 中断概念：中断源、优先级、中断嵌套、中断服务函数
- [x] 定时器 T0/T1：时钟与计数单元、TMOD/TCON 寄存器
- [x] 定时器工作模式与初值计算（模式 1、模式 2 自动重装）
- [x] 定时器应用：流水灯、定时器时钟闹钟

## 阶段四：通信与总线

- [x] 串口 UART：硬件电路（TXD/RXD 交叉接线）、TTL/RS232/RS485 电平标准
- [x] STC89C52 的串口工作模式（模式 0~3）与数据帧格式（8 位 / 9 位）
- [x] 波特率计算与常用初值速查（11.0592 MHz）
- [x] 串口收发调试：HEX 模式与文本模式的区别

- [ ] I2C 总线：AT24C02 EEPROM 读写
