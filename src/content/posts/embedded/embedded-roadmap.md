## 这篇是干什么的

嵌入式要学的东西比较杂，从软件到硬件都有。这篇把路线整理成清单，按顺序推进，学完一项打一个勾。

## 阶段一：C 语言与计算机基础

嵌入式的地基，比学多少外设都重要。

- [ ] C 语言：指针、数组与指针的关系、结构体、位运算
- [ ] 关键字：`static`、`const`、`volatile`、`extern` 在嵌入式里的含义
- [ ] 内存分区：栈、堆、全局区，理解程序在单片机里怎么放
- [ ] 数据结构：链表、队列、环形缓冲区（串口收发必备）
- [ ] 进制与位操作：十六进制、按位与/或/异或、移位、寄存器位配置
- [ ] 编译链接：预处理、编译、汇编、链接，`.map` 文件与内存占用

## 阶段二：电路与硬件常识

不用会设计电路板，但要看得懂原理图和手册。

- [ ] 基本元件：电阻、电容、二极管、三极管的作用与常见接法
- [ ] 上拉/下拉电阻、去耦电容为什么要加
- [ ] 万用表与示波器的基本使用
- [ ] 看得懂原理图：电源、地、信号线、外设连接
- [ ] 学会查芯片数据手册（Datasheet）和参考手册（Reference Manual）

## 阶段三：单片机与 STM32

- [ ] 选一块开发板（STM32F103 系列入门资料最多）
- [ ] 开发环境：Keil MDK 或 STM32CubeIDE，工程创建与下载程序
- [ ] STM32CubeMX：时钟树配置、引脚分配、生成工程
- [ ] GPIO：推挽/开漏输出、上拉输入、按键消抖
- [ ] 中断与 NVIC：外部中断、中断优先级
- [ ] 定时器 TIM：基本定时、PWM 输出、输入捕获
- [ ] 串口 UART：轮询、中断、DMA 三种收发方式
- [ ] I2C / SPI：读写传感器、OLED 屏幕
- [ ] ADC：单通道与多通道采样、DMA 搬运
- [ ] 看门狗与低功耗模式

## 阶段四：实时操作系统

- [ ] RTOS 基本概念：任务、优先级、调度、上下文切换
- [ ] FreeRTOS：任务创建、延时、优先级
- [ ] 任务间通信：队列、信号量、互斥量、事件组
- [ ] 常见坑：优先级反转、栈溢出、临界区保护

## 阶段五：进阶方向

- [ ] 通信协议：CAN、Modbus、MQTT
- [ ] 嵌入式 Linux：交叉编译、设备树、驱动入门
- [ ] 常用工具链：OpenOCD、J-Link、逻辑分析仪
- [ ] 综合项目：做一个完整的小项目（采集 → 处理 → 显示 → 上报）
