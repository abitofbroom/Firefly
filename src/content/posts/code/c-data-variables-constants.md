### 一、变量（Variable）

#### 1. 定义

变量是在程序运行过程中**值可被修改**的数据。变量的类型在声明时确定，在其生命周期中不可更改。

#### 2. 声明与赋值

变量名也称为**标识符**，起到帮助程序员理解代码语义的作用。

```c
// ① 先声明，后赋值
int a;       // 变量声明
a = 10;      // 变量赋值：把 10 赋值给 a

// ② 声明与赋值同时进行
int b = 10;

printf("%d", a);  // 输出结果为 10
```

#### 3. 初始化

初始化即在声明变量时赋予初始值。C 语言不强制要求在定义时初始化，但**使用前必须初始化**，否则可能读到内存中残留的垃圾数据（数据污染），导致程序行为不可预测。

```c
int i, j;
j = i + 1;          // i 未初始化，j 的值不可预测
printf("%d", j);    // 可能打印出任意数据
```

------

### 二、常量（Constant）

#### 1. 定义

常量是值**不可被修改**的数据，一旦赋值后在整个程序运行期间保持不变。

#### 2. 声明与赋值

由于常量不可修改，"先声明后赋值"的方式等同于修改操作，因此常量必须**在声明时直接赋值**。

```c
// const <数据类型> <常量名> = 数据;
const int a = 100;  // 常量 a 的值无法被后续修改
```

#### 3. 命名约定

- 常量名通常**全大写**，变量名通常**小写**
- 支持大驼峰（CamelCase）和小驼峰（camelCase）命名法
- 空格用**下划线**代替（如 `MAX_SIZE`），因为标识符中不允许包含空格

### 三、数值的计算

数值计算的结果**很大程度上取决于参与运算的数据类型**。

| 表达式     | 结果       | 原因                                     |
| :--------- | :--------- | :--------------------------------------- |
| `14 / 3`   | `4`        | 整数 / 整数 → 整数除法，**截断小数部分** |
| `14.0 / 3` | `4.666...` | 浮点数 / 整数 → 浮点除法，**保留小数**   |
| `14 / 3.0` | `4.666...` | 整数 / 浮点数 → 浮点除法，**保留小数**   |

> **核心规则**：C 语言中 `int / int` 的结果仍然是 `int`（直接截断小数部分，非四舍五入）。要得到精确的浮点结果，至少将一个操作数写成浮点数形式。

### 四、代码模板备忘

#### 1. 变量声明与初始化模板

```c
#include <stdio.h>

int main() {
    // 推荐：声明时即初始化
    int age = 18;
    float price = 9.9;
    const int MAX = 100;

    printf("年龄: %d\n", age);
    printf("价格: %.2f\n", price);
    // MAX = 200;  // ❌ 编译错误：常量不可修改

    return 0;
}
```

#### 2. 数据类型影响计算结果模板

```c
#include <stdio.h>

int main() {
    int a = 14, b = 3;

    printf("整数除法: %d\n", a / b);       // 输出: 4
    printf("浮点除法: %.6f\n", (float)a / b);  // 输出: 4.666667
    printf("浮点除法: %.6f\n", a / (float)b);  // 输出: 4.666667

    return 0;
}
```

### 五、与已有知识点的联动

| 已学知识点                | 关联说明                                                     |
| :------------------------ | :----------------------------------------------------------- |
| **C++ 的 `int/int` 陷阱** | C 语言中整数除法截断小数的规则，与之前洛谷错题本中 `8/16` 等题目完全一致 |
| **`&` 取地址**            | `scanf("%d", &a)` 中的 `&` 本质是获取变量在内存中的地址，将输入数据写入该地址 |
| **变量初始化**            | 与 C++ 笔记中"局部变量不初始化会读到垃圾数据"的规则完全一致  |
| **`printf` vs `cout`**    | C 语言使用 `printf` 格式化输出，C++ 更常用 `cout <<`，但底层原理相通 |

### 六、学习体悟

1. **关于 `%d` 和 `&` 的初印象**：刚开始觉得这些符号很奇怪，后来理解了"占位符"和"地址"的概念，才算真正迈过门槛。
2. **数据类型决定计算结果**：第一次意识到 `14/3` 和 `14.0/3` 结果不同，深刻理解了"类型"在 C 语言中的重要性——它不仅是数据的标签，更是行为的控制器。
3. **初始化不是可选项**：不初始化变量看似省了一行代码，但可能引入难以排查的运行时 Bug，养成"声明即初始化"的习惯至关重要。

------

### 七、一句话总结

> C 语言中，**变量**是可变的内存单元（使用前必须初始化），**常量**是不可变的内存单元（声明时必须赋值且通常大写命名），而**数值计算的结果类型由操作数类型决定**——整数运算截断小数，浮点运算保留精度。
