> **核心主题**：表达式构成、运算符分类、复合赋值、自增自减、临时变量交换

### 表达式

#### 1. 什么是表达式？

表达式由两部分组成：
- **运算符**：告诉数据如何计算
- **算子**：参与计算的数据本身

#### 2. 解决问题的思考框架

拆解问题时，可以从三个角度思考：
1. 会产生什么类型的数据？
2. 怎么储存？
3. 怎么计算？

#### 3. 单位换算技巧（非十进制计算）

对于非十进制的计算，可以先把大单位统一转化为小单位，再通过取余和除法分别得到目标结果。

**示例：将 500 分钟转换为小时和分钟**

```c
int a = 500;

int min = a % 60;   // 取余 → 剩余分钟数：20
int hour = a / 60;  // 除法 → 整小时数：4
```

### 二、运算符

#### 1. 运算符分类

| 类型           | 说明               | 示例                    |
| :------------- | :----------------- | :---------------------- |
| **单目运算符** | 只需一个算子       | `++`、`--`、`-`（负号） |
| **双目运算符** | 需要两个算子       | `+`、`-`、`*`、`/`、`%` |
| **多目运算符** | 需要三个及以上算子 | `?:`（条件运算符）      |

> **优先级规则**：单目运算符 > 双目运算符；其中赋值运算符 `=` 的优先级**最低**。

**示例说明优先级**：

```c
int a = 1, b = 0;
b = a + 1;   // 先计算 a + 1 = 2，然后才执行赋值 b = 2
```

#### 2. 复合赋值运算符

`+`、`-`、`*`、`/`、`%` 可以与 `=` 结合，形成复合赋值运算符（中间无空格）。

| 写法     | 等价于      |
| :------- | :---------- |
| `a += 8` | `a = a + 8` |
| `a -= 4` | `a = a - 4` |
| `a *= 4` | `a = a * 4` |
| `a /= 4` | `a = a / 4` |
| `a %= 4` | `a = a % 4` |

#### 3. 递增 `++` 与递减 `--`

- `++` 表示 **+1**
- `--` 表示 **-1**

##### ⚠️ 前缀与后缀的区别

| 写法          | 返回值   | 最终效果    |
| :------------ | :------- | :---------- |
| `a++`（后缀） | **旧值** | `a` 最终 +1 |
| `++a`（前缀） | **新值** | `a` 最终 +1 |

**示例**：

```c
int a = 5;
int b = a++;   // b = 5，a = 6（先取旧值，再自增）
int c = ++a;   // c = 7，a = 7（先自增，再取新值）
```

### 算法：交换两个变量的值

#### 核心认知

计算机只能**一步一步**执行指令，无法直接一步完成两个变量的交换，因此需要**引入临时变量**作为中转。

#### 标准写法

```c
int a = 1, b = 0, t;

t = a;   // ① 先把 a 的值存到临时变量 t
a = b;   // ② 再把 b 的值赋给 a
b = t;   // ③ 最后把 t 中存的原始 a 值赋给 b
```

#### 执行过程图解

| 步骤 | 操作    | `a` 的值 | `b` 的值 | `t` 的值 |
| :--- | :------ | :------- | :------- | :------- |
| 初始 | —       | `1`      | `0`      | `?`      |
| ①    | `t = a` | `1`      | `0`      | `1`      |
| ②    | `a = b` | `0`      | `0`      | `1`      |
| ③    | `b = t` | `0`      | `1`      | `1`      |

最终 `a=0`，`b=1`，交换成功 ✅
