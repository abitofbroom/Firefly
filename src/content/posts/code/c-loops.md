> **核心内容**：三种循环结构的执行逻辑、语法规范及猜数游戏实战

------

## 1. while 循环

**执行逻辑**：**先判断，后执行**。如果初始条件不满足，循环体可能一次都不执行。

### 语法规范

```c
while (判断条件) {
    // 循环体代码
    code;
}
```

------

## 2. do-while 循环

**执行逻辑**：**先执行，后判断**。无论条件是否成立，循环体**至少会执行一次**。

### 语法规范

```c
do {
    // 循环体代码
    code;
} while (判断条件); //  注意：此处必须要有分号 ;
```

------

## 3. 实战演练：猜数游戏

> **编程思路**：先将程序的执行过程用文字描述一遍，理清逻辑后，再逐步转化为代码。

### 逻辑梳理

1. 生成一个随机数。
2. 声明变量记录用户猜的数字和猜测次数。
3. 获取用户输入。
4. 判断是否猜对。
5. 若未猜对，根据大小给出提示，并继续循环。

### 代码实现

#### 版本一：使用 `while` 循环

```c
int main() {
    srand(time(0)); // 设置随机数种子
    
    int n = 0;            // 记录猜测次数
    int guess_num = 0;    // 记录用户猜的数字
    int random = rand() % 100 + 1; // 生成 1~100 的随机数

    // 先获取第一次输入（因为 while 是先判断后执行）
    printf("输入猜的数字: ");
    scanf("%d", &guess_num);
    n++;

    // 只要没猜对，就一直循环
    while (guess_num != random) {
        if (guess_num > random) {
            printf("大了\n");
        } else if (guess_num < random) {
            printf("小了\n");
        }

        printf("输入猜的数字: ");
        scanf("%d", &guess_num);
        n++;
    }

    printf("猜到答案猜了 %d 次\n", n);
    return 0;
}
```

#### 版本二：使用 `do-while` 循环（推荐）

```c
int main() {
    srand(time(0)); // 设置随机数种子
    
    int n = 0;            // 记录猜测次数
    int guess_num = 0;    // 记录用户猜的数字
    int random = rand() % 100 + 1; // 生成 1~100 的随机数

    do {
        n++;
        printf("输入猜的数字: ");
        scanf("%d", &guess_num); //  scanf 输入要记得 &，不然无法改变对应变量的值

        if (guess_num > random) {
            printf("大了\n");
        } else if (guess_num < random) {
            printf("小了\n");
        }
        
    } while (guess_num != random); // 猜对后退出循环

    printf("猜到答案猜了 %d 次\n", n);
    return 0;
}
```

## 4. for 循环

**执行逻辑**：初始化 → 判断条件 → 执行循环体 → 更新表达式 → 再次判断，直到条件不满足。

### 语法规范

```c
for (初始化表达式; 判断条件; 更新表达式) {
    // 循环体代码
    code;
}
```

### 执行顺序

1. 先执行**初始化表达式**（仅执行一次）。
2. 判断**判断条件**：若为真则执行循环体，若为假则退出循环。
3. 执行完循环体后，执行**更新表达式**。
4. 回到第 2 步，重复执行。

> **注意**：`for` 循环的三个表达式都可以省略，但**分号不能省**。例如 `for(;;)` 是死循环。

------

### 实战：猜数游戏（for 版本）

> **编程思路**：猜数游戏的循环次数不确定，因此 `for` 循环的初始化、条件、更新需要灵活设计。这里使用 `for(;;)` 实现死循环，猜对后用 `break` 跳出。

#### 逻辑梳理

1. 生成随机数，声明变量记录猜测次数。
2. 进入 `for(;;)` 死循环。
3. 输入猜的数字，次数 +1。
4. 判断是否猜对：猜对则 `break` 跳出；没猜对则提示大小，继续循环。

#### 代码实现

**基础写法（推荐）**：

```c
int main() {
    srand(time(0)); // 设置随机数种子
    
    int n = 0;            // 记录猜测次数
    int guess_num = 0;    // 记录用户猜的数字
    int random = rand() % 100 + 1; // 生成 1~100 的随机数

    // for(;;) 等价于 while(1)，是死循环的常见写法
    for (;;) {
        n++;
        printf("输入猜的数字: ");
        scanf("%d", &guess_num); //  scanf 输入要记得 &

        if (guess_num == random) {
            break; // 猜对了，跳出循环
        } else if (guess_num > random) {
            printf("大了\n");
        } else {
            printf("小了\n");
        }
    }

    printf("猜到答案猜了 %d 次\n", n);
    return 0;
}
```

**进阶写法（了解即可）**：
如果想把输入、判断、计数都放在 `for` 的三个表达式中，可以这样写：

```c
int main() {
    srand(time(0));
    
    int n = 0;
    int guess_num = 0;
    int random = rand() % 100 + 1;

    // 初始化：输入第一次；条件：没猜对；更新：次数+1并再次输入
    for (printf("输入猜的数字: "), scanf("%d", &guess_num), n = 1;
         guess_num != random;
         n++, printf("输入猜的数字: "), scanf("%d", &guess_num))
    {
        if (guess_num > random) {
            printf("大了\n");
        } else if (guess_num < random) {
            printf("小了\n");
        }
    }

    printf("猜到答案猜了 %d 次\n", n);
    return 0;
}
```

> **说明**：这种写法把多个操作塞进了 `for` 的表达式里，虽然紧凑，但**可读性较差**，不推荐新手使用。更推荐上面的 `for(;;)` + `break` 写法，逻辑清晰。

## 5. 三种循环的对比总结

| 循环类型   | 执行逻辑                    | 适用场景                                 |
| ---------- | --------------------------- | ---------------------------------------- |
| `while`    | 先判断，后执行              | 循环次数不确定，且可能一次都不执行       |
| `do-while` | 先执行，后判断              | 循环体至少执行一次，如菜单显示、输入验证 |
| `for`      | 初始化 → 判断 → 执行 → 更新 | 循环次数明确，或需要集中管理循环变量     |

### 核心小贴士

- `for(;;)` 和 `while(1)` 都是死循环，猜数游戏这类“不知道要循环几次”的场景，可以用它们配合 `break` 使用。
- 如果循环次数明确（比如“限制最多猜 10 次”），用 `for(int i = 0; i < 10; i++)` 更合适。
- 三种循环在底层逻辑上可以互相转换，实际开发中选择**最贴合业务逻辑、可读性最高**的一种即可。
