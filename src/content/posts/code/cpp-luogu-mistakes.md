### 一、核心知识点图谱

#### 1. 整数除法 vs 浮点数除法

| 写法            | 结果         | 说明                 |
| :-------------- | :----------- | :------------------- |
| `500 / 3`       | `166`        | 整数除法，截断取整   |
| `500.0 / 3`     | `166.666...` | 浮点数除法，保留小数 |
| `4 / 3`         | `1`          | 整数除法，结果为 1   |
| `4.0 / 3`       | `1.333...`   | 浮点数除法           |
| `(double)4 / 3` | `1.333...`   | 强制转换后浮点除法   |

> 💡 **黄金法则**：**只要结果需要小数，两个操作数中至少有一个是浮点数。**

#### 2. 向上取整公式（正整数，重点背诵）

```cpp
int ceil_result = (a + b - 1) / b;   // a/b 向上取整
```

**应用场景**：P5709 苹果和虫子

- 时间过了 `s` 分钟，吃一个苹果要 `t` 分钟。
- 如果 `s = 5, t = 10`，实际吃了 `0.5` 个苹果，但**第一个苹果已经不完整了**。
- 向下取整 `5/10 = 0` ❌（误以为还有 10 个完整苹果）
- 向上取整 `(5+9)/10 = 1` ✅（第一个被咬过，只剩 9 个完整）
- **结论**：只要 `s` 不是 `t` 的整数倍，就说明“正在吃”下一个苹果，那个苹果已经不完整了。

#### 3. 字符与 ASCII 码运算

| 表达式           | 结果             | 说明                             |
| :--------------- | :--------------- | :------------------------------- |
| `'M' - 'A'`      | `12`             | 字母之间的偏移量                 |
| `'M' - 'A' + 1`  | `13`             | M 是第 13 个字母                 |
| `char('A' + 17)` | `'R'`            | A 往后数 17 个，得到第 18 个字母 |
| `char(13)`       | 回车符（不可见） | ❌ 不要用 `char` 存数字再输出     |

> 💡 **记忆点**：
> - 字符相减结果是 `int`，想输出数字就**直接 `cout`**，不要存成 `char`。
> - 字符字面量必须加**单引号**：`'A'` 不是 `A`。

#### 4. 常用数学公式速查

| 公式         | C++ 实现                  |
| :----------- | :------------------------ |
| 圆周长       | `2 * π * r`               |
| 圆面积       | `π * r * r`               |
| 球体积       | `4.0 / 3 * π * r * r * r` |
| 长方体对角线 | `sqrt(长*长 + 宽*宽)`     |
| 平方根       | `sqrt(x)`                 |
| 立方根       | `cbrt(x)`                 |

### 今日错题与认知纠偏

#### ❌ 错题1：P2433 问题3 —— 输出格式错误

- **错误代码**：
  ```cpp
  cout << 14/4 << " " << (14/4)*4 << 14-(14/4)*4;
  ```
- **错因分析**：
  1. 题目要求“每个数字一行”，用空格分隔导致格式错误。
  2. 第三个数字前漏掉了 `<<` 运算符，导致拼接错误。
- **正确写法**：
  ```cpp
  cout << 14 / 4 << "\n"
       << (14 / 4) * 4 << "\n"
       << 14 - (14 / 4) * 4 << endl;
  ```
- **记忆口诀**：**输出格式逐字对，换行空格要分清。**

#### ❌ 错题2：P2433 问题4 —— 缺分号 + 缺头文件 + 整数除法

- **错误代码**：
  ```cpp
  double i = 500.0/3      // ❌ 缺分号
  cout << setprecision(6) << i;   // ❌ 缺 <iomanip>
  ```
- **错因分析**：
  1. 第一行末尾缺少分号，编译报错。
  2. `setprecision` 在 `<iomanip>` 中，未包含导致编译报错。
  3. 如果用 `500/3` 则是整数除法，结果为 `166`，丢失小数。
- **正确写法**：
  ```cpp
  #include <iomanip>   // 文件顶部加上
  
  double i = 500.0 / 3;
  cout << setprecision(6) << i << endl;
  ```
- **记忆口诀**：**setprecision 要记牢，iomanip 不可少；浮点除法写 .0，行末分号不能掉。**

#### ❌ 错题3：P2433 问题6 —— 把注释当代码写

- **错误代码**：
  ```cpp
  cout << sqrt(117) ≈ 10.8167;   // ❌ ≈ 不是 C++ 合法运算符
  ```
- **错因分析**：`≈` 是数学符号，不是 C++ 运算符，编译直接报错。应让程序自己计算，而不是硬编码近似值。
- **正确写法**：
  ```cpp
  cout << sqrt(9 * 9 + 6 * 6) << endl;
  ```
- **记忆口诀**：**数学符号全换掉，程序自己算最可靠。**

#### ❌ 错题4：P2433 问题8 —— 周长公式少乘 2

- **错误代码**：
  ```cpp
  cout << 5 * 3.141593 << "\n"   // ❌ 周长 = πr，少了 2
  ```
- **错因分析**：圆周长公式是 `2 * π * r`，写成 `π * r` 结果差了一倍。
- **正确写法**：
  ```cpp
  cout << 2 * 5 * 3.141593 << "\n"
       << 5 * 5 * 3.141593 << "\n"
       << 4.0 / 3 * 5 * 5 * 5 * 3.141593 << endl;
  ```
- **记忆口诀**：**周长 2πr，不是 πr。**

#### ❌ 错题5：P2433 问题12 —— 字符运算与输出错误

- **错误代码**：
  ```cpp
  char M_location = 'M' - 'A' + 1;   // 结果为 13，但存成了 char
  cout << M_location << "\n" << char(A + 17);   // ❌ A 未定义
  ```
- **错因分析**：
  1. `'M' - 'A' + 1` 结果是整数 `13`，但存成 `char` 后变成 ASCII 码 13（回车符），输出不可见。
  2. `char(A + 17)` 中的 `A` 未定义，应为 `'A'`。
- **正确写法**：
  ```cpp
  cout << 'M' - 'A' + 1 << "\n";      // ✅ 直接输出整数 13
  cout << char('A' + 17) << endl;     // ✅ 输出 'R'
  ```
- **记忆口诀**：**数字别存 char，字符加引号。**

#### ❌ 错题6：P2433 问题13 —— 整数除法导致体积计算错误

- **错误代码**：
  ```cpp
  cout << cbrt(4/3 * (4*4*4 + 10*10*10));   // ❌ 4/3 = 1
  ```
- **错因分析**：`4/3` 是整数除法，结果为 `1`，体积被严重低估。
- **正确写法**：
  ```cpp
  double volume = 4.0 / 3 * 3.141593 * (4*4*4 + 10*10*10);
  int edge = (int)cbrt(volume);   // 向下取整（舍去小数）
  cout << edge << endl;
  ```
- **记忆口诀**：**需要小数写 .0，整数除法要当心。**

#### ❌ 错题7：P2433 问题14 —— 答非所问

- **错误代码**：
  ```cpp
  cout << 40;   // ❌ 输出的是降价额，不是定价
  ```
- **错因分析**：方程解出降价 `40` 或 `60` 元，定价为 `110 - 40 = 70` 或 `110 - 60 = 50`，取较小者 `50`。
- **正确写法**：
  ```cpp
  cout << 50 << endl;
  ```
- **记忆口诀**：**看清楚问什么，过程值和答案要分清。**

#### ✅ 正确案例：P5709 苹果和虫子 —— 向上取整巧用

> **题目**：`m` 个苹果，吃一个要 `t` 分钟，过了 `s` 分钟，还剩几个完整的苹果？
> **关键坑**：`t` 可能为 0，且“正在吃”的那个苹果已经不完整了。

- **正确代码**：
  ```cpp
  #include <iostream>
  using namespace std;
  
  int main() {
      int m, t, s;
      cin >> m >> t >> s;
  
      if (t == 0) {      // ⚠️ 防止除以 0
          cout << 0;
          return 0;
      }
  
      int eaten = (s + t - 1) / t;   // ✅ 向上取整：正在吃的也算不完整
      if (eaten > m) eaten = m;
  
      cout << m - eaten << endl;
      return 0;
  }
  ```

- **为什么向上取整**：
  | 场景         | 向下取整 (`s/t`) | 向上取整 `((s+t-1)/t)` | 物理含义               |
  | :----------- | :--------------- | :--------------------- | :--------------------- |
  | `s=5, t=10`  | `0` ❌            | `1` ✅                  | 第一个吃了一半，不完整 |
  | `s=10, t=10` | `1` ✅            | `1` ✅                  | 刚好吃完一个           |
  | `s=15, t=10` | `1` ❌            | `2` ✅                  | 第二个吃了一半，不完整 |

### 代码模板备忘（最佳实践版）

#### 1. 浮点数输出（保留有效数字 / 固定小数位）

```cpp
#include <iomanip>

double x = 500.0 / 3;

// 保留 6 位有效数字（默认模式）
cout << setprecision(6) << x << endl;   // 166.667

// 保留 2 位小数（fixed 模式）
cout << fixed << setprecision(2) << x << endl;   // 166.67
```

#### 2. 向上取整（苹果和虫子）

```cpp
int eaten = (s + t - 1) / t;   // 向上取整
if (eaten > m) eaten = m;      // 不能超过总数
```

#### 3. 字符转字母序号 / 序号转字母

```cpp
// 字母 → 序号（从 1 开始）
int pos = 'M' - 'A' + 1;        // 13

// 序号 → 字母（从 1 开始）
char letter = char('A' + 17);   // 'R'（第 18 个）
```

### 复盘自检清单
