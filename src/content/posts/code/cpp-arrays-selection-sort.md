## 一、 核心知识点总结

### 1. 数组作为函数参数的三种等价形式

在 C++ 中，数组传入函数时会发生**退化（Decay）**，以下三种写法在编译器眼中完全等价：

```cpp
void func(int arr[]);      // 形式1：不指定长度（推荐，配合length参数使用）
void func(int arr[10]);    // 形式2：指定长度（仅起文档作用，编译器忽略数字）
void func(int *arr);       // 形式3：指针形式（揭示本质）
```

> ⚠️ **关键认知**：无论哪种写法，形参本质上都是 `int*` 指针。因此在函数内部 `sizeof(arr)` 得到的是**指针大小**（64位系统为8字节），而非数组总大小。**必须额外传递 `length` 参数**。

### 2. 选择排序算法核心原则

| 阶段           | 职责                   | 允许的操作                         | 禁止的操作           |
| -------------- | ---------------------- | ---------------------------------- | -------------------- |
| 内层循环       | 查找未排序部分的最小值 | 只读比较、更新 `min` / `min_index` | 修改原数组、交换元素 |
| 外层循环体末尾 | 将最小值归位           | 一次性三步交换                     | 重复赋值、条件外交换 |

### 3. 动态内存管理三要素

- **配对原则**：`new[]` 必须对应 `delete[]`，不可混用 `delete`。
- **生命周期**：动态数组在堆上分配，不会随函数返回而销毁，适合跨函数使用。
- **初始化**：`new int[10]{...}` 是 C++11 语法，支持列表初始化；旧标准需手动循环赋值。

## 二、 错题本（历史错误归档）

### ❌ 错题1：内层循环中提前写入原数组

- **错误代码**：`parr[i] = min;` 写在内层 `for` 循环花括号内
- **错因分析**：查找阶段尚未结束，`min_index` 仍在变化。提前写入会覆盖未比较的元素，导致后续比较基于被篡改的数据。
- **正确做法**：删除该行。内层循环只产出 `min_index`，写入操作由外层循环末尾的交换完成。
- **记忆口诀**：**内层只记不换位，外层结束才交换**。

### ❌ 错题2：在未初始化的辅助数组上执行交换

- **错误代码**：`tmp = parr_new[i]; parr_new[i] = parr[min_index]; ...`
- **错因分析**：`new int[10]` 未初始化时内容为随机垃圾值。用垃圾值参与交换，结果必然混乱。且选择排序本身是原地算法，无需辅助数组。
- **正确做法**：直接在原数组上交换。若确实需要辅助空间（如归并排序），必须先填充有效数据再操作。

### ❌ 错题3：误用指针解引用拷贝整个数组

- **错误代码**：`*parr = *parr_new;`
- **错因分析**：`*parr` 等价于 `parr[0]`，仅是单个元素的赋值。该语句永远只复制第一个元素，其余元素全部丢失。
- **正确做法**：逐元素循环拷贝，或使用 `memcpy(parr, parr_new, length * sizeof(int));`。对于选择排序，直接使用原地排序消除拷贝需求。

### ❌ 错题4：内层循环冗余的起始判断

- **错误代码**：`j = i` 起步 + `if (i == j)` 单独初始化
- **错因分析**：`parr[i]` 作为初始最小值是已知事实，无需参与比较。每次内层迭代都执行 `i==j` 判断是无意义的开销。
- **正确做法**：内层循环从 `j = i + 1` 开始，`min` 和 `min_index` 在进入内层循环前直接初始化。

## 三、 ✅ 最终正确模板（背诵级）

```
void selectionSort(int arr[], int length) {
    for (int i = 0; i < length - 1; i++) {
        int minIndex = i;

        // ① 内层只读查找，从 i+1 开始
        for (int j = i + 1; j < length; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;  // 只记录下标，绝不修改 arr
            }
        }

        // ② 内层结束后，一次性交换（避免自身交换）
        if (minIndex != i) {
            int tmp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = tmp;
        }
    }
}
```

## 四、 复盘自检清单

每次手写选择排序后，默念三个检查点：

| #    | 检查项                  | 通过标准                                   |
| ---- | ----------------------- | ------------------------------------------ |
| 1    | 内层是否纯净？          | 内层循环中没有 `arr[...] = ...` 的写入语句 |
| 2    | 交换位置对不对？        | 交换代码在内层 `}` 之后、外层 `}` 之前     |
| 3    | 有无多余拷贝/辅助数组？ | 全程原地操作，无 `new` 额外数组            |
